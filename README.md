# Table & Thyme — Restaurant App

A React Native / Expo restaurant application developed for MAD Assignment 1.

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the app:

```bash
npx expo start
```

You can open the app using **Expo Go**, an **Android emulator**, **iOS simulator**, or a **web browser**.
